# Vipasana — Portfolio Website

> Modern, high-performance personal portfolio of **Vipasana** — Digital Media Specialist, Social Media Manager, and Web Developer.

---

## ✨ Features & Highlights

- **Episodic Narrative**: Curated sections showcasing Bio, Professional Timeline, Skill Arcs, Interactive Vault, and Credentials.
- **Cinematic 3D Animations**:
  - GSAP physics-based mouse cursor and dynamic spotlight.
  - Interactive 3D holographic tilt poster with specular sheen.
  - Scroll-triggered stacked cards for work experience.
  - 3D cylindrical arc carousel for technical capabilities.
  - Interactive project vault with animated cover folder and responsive grid.
- **Rich Project Previews**:
  - Vibrant Netflix-style project cover previews for 10 real production web applications and social media campaigns.
  - Instant live launch and repository actions.
- **Interactive Credentials & Awards**:
  - Clean verified credential cards with on-click full-resolution certificate inspection modal.
- **Modern Tech Stack**:
  - **Framework**: Next.js 14 (App Router)
  - **Language**: TypeScript
  - **Styling**: Tailwind CSS
  - **Animation Libraries**: GSAP, ScrollTrigger, Framer Motion
  - **Icons**: Lucide React
  - **Deployment**: Vercel

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
